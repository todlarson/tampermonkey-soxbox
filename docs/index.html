🐵Sox Box Add-ons

Extra reports for Sox Box at dsfp.soxbox.co. They appear under Reports › 🐵 TamperMonkey.

Step 1: Set up your browser (once)

The add-ons run inside a free browser extension called Tampermonkey. You only do this once per browser.

  1. Install Tampermonkey for your browser.
  2. Allow it to run add-ons:
    Chrome
    Go to chrome://extensions, click Details on Tampermonkey, and turn on Allow User Scripts. If you don't see that switch, turn on Developer mode at the top right of the same page instead.
    Edge
    Go to edge://extensions and turn on Developer mode. If Tampermonkey's Details show Allow User Scripts, turn that on too.
    Firefox
    Nothing extra to do.

Step 2: Install the reports you want

Click Install, then click Install again on the Tampermonkey screen that opens. Updates install automatically after that.

Not showing up?

  • Reload the Sox Box page after installing.
  • Check that Allow User Scripts (or Developer mode) is on, as in Step 1.
  • Open the Tampermonkey dashboard and make sure the report is switched on.
  • On a Sox Box page, the Tampermonkey toolbar icon should show a number. No number means no add-ons are running there.

Your data

The reports read data from Sox Box while you're signed in and show it on your screen only. Nothing is downloaded, saved, or sent anywhere else.
